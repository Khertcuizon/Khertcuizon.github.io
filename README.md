# Khert Cuizon Portfolio — React

A React + Vite conversion of the original multi-page GitHub Pages portfolio.

## Run locally
1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL Vite prints.
4. Run `npm run build` to create the production build in `dist/`.

## Deploy to GitHub Pages
Run `npm run build`, then publish the `dist/` directory using GitHub Pages (or configure a GitHub Actions workflow to build and publish it). The app keeps the original `.html` paths so the portfolio's internal links continue to work.
